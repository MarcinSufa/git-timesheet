# Templates

A template is an HTML page with placeholders; `render.py` fills them and turns
the page into a PDF. The built-in template is
`${CLAUDE_SKILL_DIR}/assets/default.html` (read-only). User templates live in
`<data dir>/templates/<name>.html` (see [profiles.md](profiles.md)).

## Placeholders

| Placeholder | Value |
|---|---|
| `{{lang}}` | language code (`<html lang>`) |
| `{{title}}` | "Weekly Timesheet" in the chosen language |
| `{{member_label}}`, `{{member}}` | "Member" label and the member's name |
| `{{period_label}}`, `{{period}}` | "Period" label and the week, e.g. `1 Apr 2026 – 5 Apr 2026` (clipped to the range) |
| `{{total_label}}`, `{{total}}` | "Total Time" label and the week total |
| `{{table}}` | the whole `<table class="timesheet">` (required) |

Every value is HTML-escaped. A template without `{{table}}` is rejected.

The table uses these classes, so a template restyles it with CSS only:
`th.col-entry`, `th.col-billable`, `th.col-project`, `th.col-day`,
`th.col-total`; `td.entry`, `td.billable`, `td.project`, `td.day`, `td.total`;
`th .dow`, `th .date`; `.holiday`, `.pto`, `.sick` (labels in day headers);
`tr.totals-row`; `td.overtime` (day above the configured hours, red by
default); `td.off` (weekend/holiday/PTO/sick cells). Page size and margins come
from the template's `@page` rule (default A4 landscape, 20 mm).

The table structure (columns: Time Entries, Billable, Projects, one column per
day Mon-Sun, Total; a totals row) is fixed. A layout that needs different
columns is a change to `render.py`, not to a template.

## Converting a pre-1.1 template

Templates generated by 1.0.x contain a hand-built `<table>`. Keep the `<head>`
and header markup, replace the table (and any sample rows) with `{{table}}`,
replace hard-coded name/period/total text with the placeholders above, and map
the old CSS selectors to the classes listed here.

## `--import-template FILE` (also setup option "match my company's format")

1. Read the PDF, PNG/JPG or DOCX with the `Read` tool.
2. Note the layout: logo and branding, title and font sizes, header metadata
   (member, period, total — labels and layout), day header format (Mon vs
   Monday, date format), time format, empty-cell style (dash, blank, 0:00),
   colours (header background, borders, zebra rows), footer (page numbers,
   signature lines, notes), page orientation and size.
3. Copy `assets/default.html` to `<data dir>/templates/<name>.html` and change
   only its `<style>`, header markup and `@page` rule to match. Keep every
   placeholder. Copy layout only — never names, projects, hours or "Billable"
   values from the sample.
4. Preview: render one week with `render.py --format pdf --template <name>`
   (or `--format html` and open it), show the result.
5. Ask:
   > A) Perfect, save it!
   > B) Needs adjustments (I'll describe what to change)
   > C) Start over with a different approach

   Loop until A.

## `--list-templates`

List `default` first (built-in, read-only), then each file in
`<data dir>/templates/` with the date it was saved:

> Saved templates (3):
>
>   - **default** — built-in, read-only
>   - **company-x** — imported 2026-04-22 from `our-timesheet.pdf`
>   - **acme-template** — imported 2026-03-10 from `acme.docx`

If a browser tool is available ([pdf.md](pdf.md)), a screenshot of one sample
week per template helps the user recognise them.

## `--edit-template <name>`

Render the template with sample data and show it, then ask what to change
("make the header bigger and bold", "switch to A4 portrait", "change the
brand colour to #0055AA", "add the company logo at top-right" — then ask for
the image path and embed it). Apply the change, render again, show before and
after, and ask:

> A) Looks good, save
> B) Needs more adjustment (describe)
> C) Revert and start over

Loop on B until A. The built-in **default** cannot be edited: copy it to a new
name first.

## `--delete-template <name>`

The built-in **default** cannot be deleted.

> Delete template **company-x**? This is permanent and cannot be undone.
> Profiles still referencing this template will fall back to **default** until updated.
>
> A) Yes, delete it
> B) No, keep it

After deleting, offer to update the profiles that referenced it.
