# Languages

`render.py --lang CODE` (or `settings.language`) translates the title, header
labels, column headers, day and month abbreviations, day-off labels and
Yes/No. Built in: `en`, `pl`, `de`, `fr`, `es`, `nl` (the `LABELS` table in
`scripts/render.py`; the tables below are the same values).

Other languages (`pt`, `it`, `ja`, …): write a JSON file with the same keys,
translated, and pass it with `--labels FILE`; missing keys fall back to
English. Keys: `title`, `member`, `period`, `totalTime`, `timeEntries`,
`billable`, `projects`, `total`, `holiday`, `pto`, `sick`, `noProject`, `yes`,
`no`, `days` (7 items, Monday first), `months` (12 items).

```json
{"title": "Folha de horas semanal", "member": "Membro", "period": "Período",
 "days": ["Seg", "Ter", "Qua", "Qui", "Sex", "Sáb", "Dom"]}
```

Holiday names stay in the country's language (PL, DE, FR, NL) whatever the
report language, because they are proper nouns; other countries use English
names. The CSV header row stays English (`User, Time Entry, Task, Project,
Billable, ...`) because importers expect those column names; only cell values
(Yes/No, day-off labels) are translated. Messages in chat follow the user's
language.
